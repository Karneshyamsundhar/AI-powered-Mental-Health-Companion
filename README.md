# 🧠 AI-Powered Mental Health Companion

An AI-driven web application that offers real-time, empathetic conversations to support users' emotional well-being. Built to provide a safe, private space for people to share their thoughts, reduce stress, and track their mood over time.

🔗 **Live Demo:** [ai-powered-mental-health-companion.vercel.app](https://ai-powered-mental-health-companion.vercel.app)

---

## 📌 Overview

Mental health support isn't always accessible — long wait times, cost, and stigma often stop people from reaching out. This project explores how AI can act as a first line of emotional support: not a replacement for therapy, but an always-available companion for daily check-ins, mood tracking, and empathetic conversation.

---

## ✨ Features

- 💬 **Empathetic AI Conversations** — Natural, LLM-powered dialogue designed to respond with warmth and understanding.
- 📊 **Session-Based Mood Tracking** — Users can log and monitor their emotional state across sessions.
- 🔒 **Secure & Private Interface** — Built with user privacy as a core design principle, so people feel safe sharing openly.
- ⚡ **Fast & Responsive UI** — Simple, distraction-free interface optimized for daily use.

---

## 🛠️ Tech Stack

- **Frontend:** TypeScript, React
- **AI Integration:** Large Language Model (LLM) API for conversational responses
- **Deployment:** Vercel

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Karneshyamsundhar/AI-powered-Mental-Health-Companion.git

# Navigate into the project
cd AI-powered-Mental-Health-Companion/ai-therapy-companion-11

# Install dependencies
npm install

# Run locally
npm run dev
```

The app will be available at `http://localhost:3000`.
